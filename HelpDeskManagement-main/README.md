# Help Desk Management System

A web-based Help Desk Management System built using **ASP.NET Core MVC** and **ASP.NET Core Web API**. The application allows users to create, manage, update, and track support tickets through an intuitive interface.

---

## Features

- Create new support tickets
- View all tickets
- Edit existing tickets
- Delete tickets
- RESTful Web API
- ASP.NET Core MVC frontend
- Entity Framework Core integration
- SQL Server database support
- Unit testing using xUnit

## Getting Started

### Clone the repository

```bash
git clone https://github.com/abhinavashish1710/HelpDeskManagement.git
```

### Open the project

Open

```
HelpDeskManagement.sln
```

using Visual Studio 2022.

### Restore Packages

```
Build → Restore NuGet Packages
```

### Run the project

Press

```
F5
```

or

```
Ctrl + F5
```
